Written by a scraper that runs daily on GitHub Actions. It reads fernsehserien.de's streaming guide (upcoming and newly available lists) and stores it in Supabase. Confirmed means the title appeared in the "Neu verfügbar" list. Scheduled means its announced date has passed but it wasn't seen as newly available. Dropped means it left the upcoming list before its date. Nothing on this page is edited by hand.
